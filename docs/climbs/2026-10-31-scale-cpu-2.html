Outcome

CPU the hub and Postgres spend to push, link, and read an estate of 115,545 entities through the API went from 71,051 ms to 69,645 ms: +2.0% (no real change). The noise floor was 2.38%, so only changes beyond it were kept.

The held-out score, which the agent never climbed against, went from 36,370 ms to 34,287 ms (+5.7%).

The guard tests passed on the final state.

Since the last pass (2026-10-31-scale-cpu.json, which ended at 71,780 ms), the code had moved +1.0% before this pass began.

What changed and why it is better

Pass 3 on the same estate of 115,535 entities, scored on CPU, with a fresh baseline whose noise floor is 2.4 %.

  • A rule writes its links in one statement each way. It used to insert and delete one row per statement. The target index is also built without copying a growing list for every target. Linking after the first push fell from 11 s to 1.5 s.
  • A neighbour is derived only when its own derived values are read. To count a repository’s services, a cold build used to derive every service, then everything each service reads: workloads, Argo apps, deployments, cluster workloads. Now a path read only for a count or a stored value stops at what is stored. Status paths and paths that read a derived value still go all the way. A cold repository grid at 38,515 entities fell from 2.6 s to 0.17 s.

Tried and not kept:

  • Cheaper derivation per entity (narrow relation reads, one source lookup per pass, no list copies): inside the noise at this size.
  • Keeping entities in title order with one shared collator: 1.9 %, inside the noise. A sort is cheap next to the build it follows.

Found along the way: the webhook test failed about one run in eight, because a local tool probed the fake webhook’s port with a GET and the fake read every request as JSON. The fake now turns away anything but a POST. That fix is its own commit.

The final run was taken with the machine’s load average at 36, which inflates CPU time too: it measured 2 % better than the baseline, where the kept attempts measured 9 %. Step by step the gains held: linking after the first push 10.9 s to 1.9 s, cold grids 13.9 s to 11.9 s.
